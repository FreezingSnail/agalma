Cross-cutting gates

  • Architecture test. B1.1 extended it with the Cargo.toml normal-dependency edge check (no impl→impl edges; agalma-ipc infrastructure). One temporary sanctioned server-host edge (harness→sandbox, B1.2) was removed in B1.3; both checks are strict at HEAD and green.
  • Contracts unchanged. git diff c63f210..HEAD --stat -- crates/agalma-contracts/ is empty: no schema, ID, trait, or error change across all extractions.
  • Consumer invariance. Each evidence doc carries its git diff --name-only proof; conductor changes are construction-site/wiring only, phase logic and activity bodies unchanged. Kernel/execution source changes were seam wiring (generics, Send bounds, serde derives for the wire) — no behavior change.
  • Test suite. At HEAD: cargo test --offline — 70 test-result groups, 0 failures (workspace + all boundary process suites; real-binary and re-exec fallback paths both exercised).

Limitations and open items

  1. ExecutionApi adapter gap (tracked: agalma-5de, B1-F1). step/recover return UnsupportedCapability over the process boundary because effect dispatch needs a handler registry that can cross it. Parity for those flows is proven at the engine-op level (ExecutionOps). The kernel remains a candidate; the production default is still the seed executor (docs/b1-execution-evidence.md).
  2. Auxiliary ledger connections (tracked: agalma-1o3, B1-F2). A few short-lived conductor helpers still open direct SQLite (secondary WAL) connections under AGALMA_LEDGER_TRANSPORT=process; the durable-state owner and export/import generation remain the supervised server.
  3. Process defaults and the execution deferral. Harness defaults to process after agalma-ud1's live Connect smoke. agalma-fez bounds peer sockets and changes ledger, workspace, and task queue to process defaults; sandbox is always process. Explicit in-process overrides remain available. Execution keeps its in-process default until CV.1 (agalma-pob.1) integrates the kernel into the production work loop. See docs/b1-f3-evidence.md §§5–6.
  4. Live OpenCode process path. agalma-ud1 proved the default process path with a paid Connect-wire run on an isolated scratch clone. FEZ peer smokes exercise real local server processes without inference; they do not establish unattended operation or the later plugin platform acceptance.

Verdict

The component map is realized for the harness, sandbox, workspace, task-queue, and ledger boundaries with full dual-binding parity, staged rebind, and rollback evidence; the execution boundary is realized at the kernel's engine surface with the ExecutionApi adapter gap explicitly tracked (agalma-5de). Residual items are tracked as agalma-1o3 and agalma-rvj. Epic agalma-0ht closes on this record.
