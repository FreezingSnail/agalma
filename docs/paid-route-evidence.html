1. Command

AGALMA_ALLOW_PAID=1 AGALMA_PROXY_LOG=1 AGALMA_IDLE_TIMEOUT_SECS=240 \
  cargo run --offline -p agalma-conductor -- work \
    --repo target/test-runs/paid-route/run-2/target \
    --state-dir target/test-runs/paid-route/run-2/state \
    --model opencode-go/deepseek-v4.1-flash \
    --harness opencode --max-tasks 1 --once

--model pins the paid route because the H3 builder class is deliberately free-first (the paid deepseek-v4.1-flash → glm-5.3-flash entries are fallbacks after the free entries, per docs/reliability-hardening.md H3); the verifier class is the tier whose paid entries lead. The override is the H3 sanctioned way to force a paid builder turn and is recorded as origin=override in the route.model decision. AGALMA_ALLOW_PAID=1 is set so the decision context carries paid_active=true.

5. OpenCode provider baseURL override (verified shape)

Verified against the OpenCode v2 provider config (docs https://opencode.ai/docs/providers/ "Base URL") and the v2 source (packages/core/src/config/discovery.ts, packages/util/src/global.ts):

  • The provider is keyed by id under provider; the endpoint is provider.<id>.options.baseURL.
  • The global config directory is OPENCODE_CONFIG_DIR when set, else $XDG_CONFIG_HOME/opencode; opencode.json there is the global config. The confined adapter sets OPENCODE_CONFIG_DIR to the checkout (the config discovery short-circuit the confine profile needs), so the override is a written-then-locally-excluded opencode.json in the checkout.
  • opencode-go uses env OPENCODE_API_KEY; the sandbox gets the dummy and the proxy injects the real bearer token.

Rendered shape (render_provider_config):

{
  "$schema": "https://opencode.ai/config.json",
  "provider": { "opencode-go": { "options": { "baseURL": "http://127.0.0.1:<port>" } } }
}

The worker's baseURL is the loopback proxy root; the proxy maps /<path> onto https://opencode.ai/zen/go/v1/<path> (the configured upstream base, AGALMA_PROVIDER_BASE), so OpenCode's POST /chat/completions becomes https://opencode.ai/zen/go/v1/chat/completions with the credential injected.

6. Deviations / notes

  1. First scratch run (run-1) failed with a config error, not an auth/quota error. Before the provider gate was added, the override was applied to every model, so the free opencode/big-pickle route was mapped onto the paid Go base and the provider returned AI.Error.InvalidRequest: Upstream request failed: Model is unavailable. The fix: point only opencode-go at the injecting proxy; free opencode routes keep the transparent CONNECT tunnel to the Zen endpoint. run-1 cost $0.00 (free model) and is retained as evidence.
  2. --model override. As above, the live proof pins the paid model because H3 builder routing is free-first; static paid eligibility (with/without credential) is covered by the deterministic tests.
  3. No git commit/push was performed in the live repo; all bd, merge, and tag activity happened in the scratch clone. bd in the live repo was only read.
