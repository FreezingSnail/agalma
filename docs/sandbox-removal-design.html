Sandbox layer removal design

Status: proposed (design, not implemented). Owner: Sol. Implementers: GPT-6 Luna / DeepSeek Flash. Supersedes the confinement boundary documented in docs/b1-sandbox-evidence.md (that file is a frozen historical receipt and is not rewritten; this document is its amendment).

1. Decision

Remove the sandbox layer entirely and replace it with a small in-process process launcher. Concretely:

  • delete the agalma-sandbox crate (Seatbelt backend, profile, server binary);
  • delete the SandboxApi contract and the agalma-ipc sandbox client/server;
  • delete the conductor's sandbox supervisor (sandbox_process.rs);
  • delete the kernel/harness socket plumbing that only existed to reach the sandbox server;
  • add one crate agalma-process exposing LocalLauncher, which owns the process-group/lifecycle logic that was previously entangled with the Seatbelt profile.

Retained properties: multiple in-flight children, environment separation, and a kill switch (whole-descendant-tree termination with evidence). Anything enforced solely by Seatbelt is dropped:

  • OS read/write confinement (the protected-oracle read-only root),
  • network-egress denial (the loopback proxy is no longer a security boundary),
  • the fail-closed profile validate/preflight gate.

The loss of the first two is a deliberate human decision, recorded as an accepted guarantee reduction in §7. It weakens docs/sf6-protected-inputs.md and the self-mutation contracts from enforced to advisory properties.

2. Motivation

All four stated drivers:

  1. Portability — sandbox-exec and the .sb profile are macOS-only, so the factory cannot run on Linux/CI without a parallel confinement path.
  2. Maintenance — sandbox-exec is deprecated (S0b open item: re-verify on every macOS upgrade); the profile carries seven parameters, an inert-slot padding rule, and an xcrun-cache carve-out that must be re-audited.
  3. Complexity — reaching a sandbox-exec wrap required a whole supervised component server, a Unix socket, two wire transports, framed-JSON clients, and parity tests, all to launch a subprocess.
  4. Dead weight — the process-group kill, liveness, and env isolation that the factory actually depends on are plain Unix and never needed Seatbelt.

4. Target architecture

4.1 Contract: agalma_contracts::process

Rename the sandbox module to process and trim the types:

// crates/agalma-contracts/src/process.rs
pub struct ProcessSpec {
    pub program: String,
    pub args: Vec<String>,
    pub cwd: String,
    pub env: BTreeMap<String, String>, // complete child environment
    pub attempt: AttemptId,            // reconciliation key
}

pub struct ProcessChild {
    pub pid: u32,
    pub pgid: u32,                     // == pid (group leader)
    pub attempt: AttemptId,
    pub started_at_unix_ms: u64,
}

pub trait ProcessApi {
    fn launch(&mut self, spec: ProcessSpec) -> Result<ProcessChild, ContractError>;
    fn alive(&self, child: &ProcessChild) -> Result<bool, ContractError>;
    fn terminate(&mut self, child: &ProcessChild) -> Result<StopEvidence, ContractError>;
}

Dropped fields: profile, attempt_dir, protected_dir, sock_dir, extra_ro_roots, extra_rw_roots. StopEvidence stays in agalma_contracts::harness. agalma-contracts remains pure (types + trait only; no spawning).

The trait is kept (not inlined to a concrete type) so the kernel test doubles (FakeLauncher/GoneLauncher/StubbornLauncher) can still be injected. It costs nothing at runtime.

4.2 Backend: new crate agalma-process

LocalLauncher is SeatbeltSandbox minus the profile:

  • launch(spec): Command::new(spec.program), args, current_dir(cwd), env_clear().envs(spec.env), process_group(0); store the tokio::Child in HashMap<u32, Child>; return ProcessChild { pid, pgid: pid, attempt, started_at_unix_ms }.
  • alive(child): /bin/kill -0 <pid>; EPERM ⇒ alive (mirrors seatbelt.rs).
  • terminate(child): group SIGTERM, explicit per-descendant signal from pgrep -g <pgid>, reap the owned child when present, verify the group is empty, escalate to SIGKILL; return StopEvidence.
  • run(spec, timeout) -> Result<ProcessOutput, ContractError>: one-shot counterpart used by the verifier (exit code is the verdict); same teardown on timeout. ProcessOutput { exit_code, stdout, stderr }.

No profile, no sandbox-exec, no preflight, no serde. /bin/kill and /usr/bin/pgrep exist on macOS and Linux; this is the portability win.

Dependency direction: agalma-process → agalma-contracts (+ tokio). No IPC.

5. Migration by area

5.1 Conductor

  • SandboxSource/SandboxProcess disappear; each activity holds a LocalLauncher (or Box<dyn ProcessApi>) directly.
  • phases.rs: SeatbeltSandbox::new() → LocalLauncher::new(); drop the profile/attempt_dir/protected_dir/sock_dir/extra_* fields from the two LaunchSpec constructions (phases.rs:1757, phases.rs:2281). The env map (which already carries TMPDIR/XDG/CARGO_*/AGALMA_PROTECTED_DIR/ AGALMA_CANDIDATE_DIR) is unchanged.
  • session.rs, work.rs, composition.rs: drop the worker.sb PRODUCT_PROFILE writes; SandboxSource::ensure() → a LocalLauncher; LiveSession.profile_path is removed. review.rs, concierge.rs, sweep.rs only mention the profile in comments — update those.
  • Phase deps (phases.rs:153,169): remove profile_path and extra_ro_roots; the harness config (config.rs:17,32) likewise drops profile_path and extra_ro_roots.
  • workers.rs: SandboxChild → ProcessChild; reconcile_survivor logic is unchanged (it already only needs alive/terminate).
  • VerifyActivity.sandboxed (phases.rs:1510) is deleted; the ActivityMode- driven branch collapses to one path. One-shot verify uses LocalLauncher::run (timeout + tree-kill); run_in_process (phases.rs:688) is retired because it has no timeout.
  • harness_process.rs: the in-process harness receives a LocalLauncher instead of a SandboxClient; the sandbox_socket init field is removed. The process-bound harness server constructs its own LocalLauncher.
  • execution_process.rs: drop the sandbox_socket parameter; the kernel server no longer receives a sandbox socket.
  • reap.rs: keep the verify-runtime/xdg-* scratch reaping (they serve env isolation, not confinement); update the naming/comments.
  • provider_proxy.rs / provider_auth.rs: kept, not deleted (§7.2).

5.2 Harness and kernel

  • harness-opencode/src/adapter.rs: Box<dyn SandboxApi + Send> → Box<dyn ProcessApi + Send>; LaunchSpec → ProcessSpec; drop profile/env plumbing and the profile_path config field.
  • harness-opencode/src/server.rs: delete connect_sandbox and SANDBOX_SOCKET_ENV; build a LocalLauncher.
  • kernel/src/engine.rs: Option<Box<dyn SandboxApi + Send>> → Option<Box<dyn ProcessApi + Send>>; with_sandbox/has_sandbox/ sandbox_mut → with_launcher/has_launcher/launcher_mut (or keep the method names if that minimizes churn — decide in the bead).
  • kernel/src/ownership.rs: reconstruct ProcessChild.
  • kernel/src/server.rs: delete SANDBOX_SOCKET_ENV; construct a LocalLauncher.
  • Cross-process kill still works: the kernel only needs alive/terminate from a pid/pgid, which is exactly the "terminate without an owned handle" path.

5.3 Build / tooling

  • Cargo.toml: remove crates/agalma-sandbox, add crates/agalma-process.
  • scripts/verify-peer-transports.sh: component loop becomes ledger workspace taskqueue kernel; smoke set drops --test sandbox_process and the expected-passing count drops 5 → 4.
  • scripts/md-to-html.mjs: not owned by these beads — another session holds staged docs-tooling work there. Regenerating the HTML set (frozen b1-sandbox-evidence.md entry included) is deferred until that work lands.

6. Interfaces deliberately preserved

  • terminate remains valid from pid/pgid alone (no owned Child), because the kernel reclaims survivors across a process boundary and after restart.
  • alive keeps the EPERM-is-alive rule.
  • reconcile_survivor keeps writing <run>/stop/<phase>-<attempt>.json evidence.
  • Attempt-scoped TMPDIR/XDG/HOME/CARGO_* env construction is untouched.
  • The provider proxy stays functional (only its security claim changes).

7. Accepted guarantee reduction

7.1 Protected-oracle read-only (SF.6)

docs/sf6-protected-inputs.md:44-49 requires the protected judge to be materialized in a read-only root outside every candidate-writable root, and requires proof the runner "cannot write protected files." Today that is enforced by Seatbelt. After removal it is advisory only: the runner still receives AGALMA_PROTECTED_DIR and the frozen commands still judge behavior, but a candidate is no longer prevented from tampering with the judge root.

Doc amendment: sf6-protected-inputs.md gains an amendment stating the read-only property is convention-only, and sf_scope_guard.rs is rewritten to stop asserting OS-enforced read-only isolation (sf_scope_guard.rs:710, :833+, :1652, all of which import SeatbeltSandbox/PRODUCT_PROFILE).

7.2 Network egress

The loopback proxy was justified by the Seatbelt loopback-only profile. After removal the harness can reach the network directly. provider_proxy.rs is kept (it still centralizes provider credentials/audit), but it is no longer a security boundary. provider_proxy_live.rs's "direct network is denied" assertion is dropped; the proxy behavior test is retained.

7.3 Fail-closed launch gate

profile::validate/preflight disappear; the only launch gate becomes spawn failure. This removes a deliberate fail-closed check but was only meaningful because a profile existed.

New — agalma-process property tests (saved in the repo)

  • Concurrency: launch N long-running children; all report alive; terminate all; each returns process_group_gone.
  • Env separation: child sees exactly the supplied env (nothing inherited); a child given no TMPDIR does not see the parent's.
  • Tree kill: parent spawns a grandchild; terminate the parent; assert the grandchild is gone and StopEvidence.process_group_gone holds.
  • Terminate-from-pid-only: build a ProcessChild from pid/pgid alone (as after a restart) and terminate it; no owned handle.
  • One-shot timeout: run(spec, short) on a sleeper returns KnownFailure and leaves no survivor.
  • Alive semantics: alive false after normal exit.

Each property test records a deterministic generation scheme (small fixed N, fixed sleep durations) and asserts independently of the implementation.

Historical acceptance receipts that referenced the sandbox boundary remain as frozen evidence; no frozen receipt is rewritten.

10. Risks and open questions

Resolved at filing (2026-10-15):

  • agalma-process placement: new workspace crate (bead agalma-ib2).
  • IMPL_CRATES classification: agalma-process is infrastructure, like agalma-ipc — deliberately not in IMPL_CRATES, because agalma-kernel and agalma-harness-opencode (impl crates) depend on it as a normal dependency.
  • md-to-html.mjs: deferred. Another session holds staged docs-tooling work (Makefile, scripts/md-to-html.mjs, docs/*.html); the removal beads do not own those files, and regeneration happens after that work lands.
  • Kernel rename: with_launcher/has_launcher/launcher_mut (bead agalma-wmk).

Remaining risks:

  • Guarantee loss is real, not cosmetic. SF.6's read-only judge and the egress boundary are removed. Downstream self-mutation policy assumes a confinement boundary; the amendment must be explicit that this is now convention. If confinement is later required for portability, a Linux namespace/bubblewrap backend could be reintroduced behind ProcessApi without re-adding the IPC/server seam.
  • Cross-process ownership. With one launcher per process (conductor, harness, kernel) instead of one shared server, termination relies entirely on pid/pgid, which the current code already supports. The harness transport defaults to Process (AGALMA_HARNESS_TRANSPORT), so the production harness server owns its LocalLauncher and the OpenCode child; the conductor keeps its own for build-probe/verify. The P4 bead adds the explicit regression: a fresh LocalLauncher terminates a child whose owning handle was dropped (pid/pgid-only path across processes/restarts).

11. Out of scope

  • Removing the provider proxy (provider_proxy.rs), which is retained.
  • Adding a replacement confinement backend.
  • Any change to ledger, workspace, taskqueue, or execution boundaries beyond the sandbox references listed above.
